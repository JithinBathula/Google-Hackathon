# AI Builder Cup 2026: overview

> Source: https://aibuildercup.com · Last verified: 2026-09-26

## What it is
The **Google Cloud AI Builder Cup** is a hackathon for builders across the **JAPAC** (Japan & Asia-Pacific) region. **Hack2skill** runs it and **Google Cloud** sponsors it. The tagline is *"Build in JAPAC. Build for the world."*

The premise:
1. Pick a real-world problem you understand.
2. Form a team of 2–4.
3. Spend a few weeks building a working AI prototype on Google Cloud.
4. Submit it for evaluation.
5. The top teams demo live at an in-person Grand Finale in **Singapore on Dec 4, 2026**, in front of Google Cloud and industry experts. Travel is sponsored.

The pitch is that something built for a local need can scale to a global one.

| | |

## Organizer disclaimer
Hack2skill operates the program independently; Google Cloud doesn't administer it directly. Google Cloud provides technical expertise, access and educational resources.
