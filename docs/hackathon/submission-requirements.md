# Submission requirements

> Sources: https://aibuildercup.com/themes.html, FAQs, official T&C · Last verified: 2026-09-26
> Deadline: **Oct 18, 2026**. The time and timezone aren't published yet.

## Technical requirements (hard gates)
1. **Google AI.** The solution must integrate Gemini-family or Gemma-family models, **or** be built with a Google agentic platform: Agent Platform, Antigravity or AI Studio.
2. **Google Cloud deployment.** It must be deployed on **Cloud Run or Firebase** (the FAQ also says "Cloud Run/GCP/Firebase"). It must be built *primarily* on the Google Cloud stack; solutions built mainly on competing clouds are disqualified.
3. **Fresh code.** Only code and assets created during the official timeline count. Pre-existing products or ongoing projects are disqualified.
4. **A working, end-to-end prototype.** A mockup or pitch deck alone doesn't qualify, and neither does a full product. It must show the idea working end to end.
5. **English** for all materials: code, docs and presentations.

## Mandatory deliverables
| # | Deliverable | Spec |
|---|---|---|
| 1 | **Live deployed URL** | Running on Cloud Run, GCP or Firebase, and reachable by judges |
| 2 | **Demo video** | **Strictly under 3 minutes.** Public YouTube, Vimeo or Google Drive link. |
| 3 | **Public GitHub repo** | Full source code |
| 4 | **Deck (PDF)** | Solution architecture **and** business case. Must cover: the vision and positive impact; how it aligns with the chosen theme; the problem it solves and who benefits; feasibility; and potential to scale. |
| 5 | **Theme** | Name the single theme you're submitting under |

## Quality expectations stated on the site
- **Functionality:** it must work and clearly solve the chosen problem.
- **Usability:** user-friendly, accessible and scalable.
- **Platform fit:** works with the specified Google Cloud tools. Think about scalability, performance, and integration with existing systems.

## Implications for us
These are our reading of the rules, not official text.
- The live URL must **stay up through judging (Oct 19 – Nov 6)** and, if we're shortlisted, **until Dec 4**. Budget for it and avoid preview-only services that might expire.
- The judges will open the public repo, so its README and architecture should be clean and easy to follow.
- The video limit is "strictly under 3:00". Aim for 2:45.
