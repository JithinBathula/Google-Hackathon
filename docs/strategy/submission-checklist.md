# Submission checklist (go/no-go)

> Deadline: **Oct 18, 2026**. Confirm the time and timezone. Requirements: [../hackathon/submission-requirements.md](../hackathon/submission-requirements.md)

## Eligibility (by Oct 4)
- [ ] Every member is 21+, a JAPAC resident, and not a student
- [ ] Team has 2–4 members and is registered on Hack2skill
- [ ] Roster is final by **Oct 4** (T&C), not Oct 11
- [ ] Everyone has joined Discord and the Hackathon Dashboard, and nobody leaves them
- [ ] Employer IP and moonlighting policy checked (see [../hackathon/terms-and-conditions.md](../hackathon/terms-and-conditions.md))

## Hard gates
- [ ] Uses Gemini or Gemma models, or Agent Platform, Antigravity or AI Studio
- [ ] Deployed on Cloud Run or Firebase
- [ ] Built primarily on Google Cloud, with no core dependency on another cloud
- [ ] All code and assets created on or after the program launch (git history will show this)
- [ ] One theme, clearly named
- [ ] Everything in English

## Deliverables
- [ ] **Live URL** works in an incognito window, with no login wall, or with demo credentials provided
- [ ] **Public GitHub repo** includes:
  - [ ] a README with the problem, architecture diagram, tech stack, setup and deploy steps
  - [ ] no secrets or `.env` files
  - [ ] a licence
- [ ] **Demo video** is strictly under 3:00 (aim for 2:45), on a public YouTube, Vimeo or Drive link, and the link works when logged out
- [ ] **Deck (PDF)** covers:
  - [ ] problem and target users
  - [ ] theme alignment
  - [ ] solution and demo screenshots
  - [ ] architecture showing the Google Cloud services used
  - [ ] how Gen AI is used and why it matters
  - [ ] impact metrics
  - [ ] feasibility and scalability
  - [ ] business case
  - [ ] team

## Operational
- [ ] Billing budget alerts set
- [ ] Gemini quotas and rate limits are enough for judges
- [ ] The URL will stay up through Nov 6, and through Dec 4 if we're shortlisted
- [ ] Fallback or demo data in place if an AI call fails
- [ ] Submitted at least 12 hours early

## If shortlisted (Nov 7)
- [ ] Choose the 2 travellers
- [ ] Start visa applications immediately
- [ ] Rehearse the live demo, with an offline backup recording
