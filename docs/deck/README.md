# Deck diagrams

Images for the three diagram slides of the submission deck. White background, sized to fill the slide body under the title. PNGs are rendered at 2× for crisp slides.

| Slide | File | What it is |
|---|---|---|
| Process flow / use-case | `process-flow.png` | Swimlane flowchart (leaver, Handover, successor) in standard notation: terminators, processes, Yes/No decisions, data store. ✦ marks the steps Gemini performs |
| Wireframes / mocks (optional) | `wireframes.png` | Four low-fidelity screens with one blue accent: written questions, the offboarding interview, Ask, and the knowledge map drawn as the constellation view |
| Technologies used | `technologies.png` | Logo wall in four groups (Google AI, Google Cloud, Google Workspace, Application), transparent background, no title. Logos are the official marks from Wikimedia Commons and the open-source `diagrams` icon set; rendered once, not generated by `gen.py` |
| Architecture | `architecture.png` | Cloud architecture diagram: users and Google Workspace outside, the Google Cloud zone with Cloud Run, Vertex AI, Firestore, Secret Manager and Cloud Build, numbered arrows with a key |

The SVGs are generated by `gen.py`. After editing it:

```bash
python3 docs/deck/gen.py docs/deck && docs/deck/render.sh "$PWD/docs/deck" "$PWD/docs/deck"   # needs Google Chrome
```
