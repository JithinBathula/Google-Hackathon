# Google Cloud AI Builder Cup 2026

This is our codebase for the [Google Cloud AI Builder Cup 2026](https://aibuildercup.com), a hackathon run by Hack2skill and sponsored by Google Cloud.

We are building a knowledge-handover agent: it captures what a departing teammate knows, asks the questions that files do not answer, and leaves a knowledge base the next person can use.

| Folder | What is in it |
|---|---|
| [`docs/`](docs/README.md) | Rules, idea, decisions, and how we plan to build it |
| `app/` | The prototype. Not started yet. |
